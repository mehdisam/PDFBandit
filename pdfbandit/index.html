Built around the document

One map. Two workflows. No silent rewrites.

PDFBandit separates what a PDF is from what you want to say, so translation and repair stay predictable.

Translate in place

Map the regions that matter, translate them, and keep the page layout intact. Source text and translated text live in separate variants.

Make PDFs selectable

Add an invisible text layer over scanned or image-only pages, so the document becomes searchable and copyable without changing how it looks.

One map, many variants

The structure is shared. Each language or working copy gets its own content file, and switching variants never throws away edits.

On-device OCR

Scanned-page text is read locally with Tesseract.js. OCR is lazy, opt-out, and never writes placeholder text when it fails.

Local-first by default

Your PDF, map, and variants stay in this browser. There is no account, no upload queue, and no server-side copy of your document.

Export what you made

Build a reconstructed PDF, or export a digitalized copy with the source text embedded as a selectable layer. The original stays untouched.

A short path from PDF to result

Map once. Then work the way you want.

No import wizard, no conversion queue. The editor opens the PDF directly in your browser.

Open the PDF

Drop in a document. PDFBandit reads it locally and remembers the session in IndexedDB.

Map the regions

Draw or detect text and figure regions. Proposals stay proposals until you confirm them.

Translate or improve

Translate into a target variant, or extract source text and make the page selectable.

Save or export

Save the map and content separately, or export a finished PDF copy. The source file never changes.

Privacy is a design choice

Your PDF is not our data.

PDFBandit runs in your browser. The document, its map, and its variants stay on your device unless you export them.

  • No account and no PDF upload to a PDFBandit server.
  • OCR and text extraction run on-device.
  • Translation text goes only to the provider you choose.
  • “Forget saved session” clears the browser copy.
